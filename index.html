六大核心客製化亮點

解決命令列新手與重度多代理使用者的所有視覺與操作痛點

🚧

1. 底部三段權限開關（Per-Session 獨立生效）

不必再記複雜的 CLI 啟動旗標！在視窗最底部直接用滑鼠點擊切換當前對話框的權限檔位，並透過 PreToolUse / PermissionRequest Hook 與狀態列色塊即時連動：

  • 💬 每次都問（預設，深石板藍）：寫檔、改檔或執行指令前每次詢問（純讀檔自動放行）。
  • 🚧 刪改才問（皇家亮藍）：日常開發最推薦！一般改碼與跑測試自動放行；只有遇到 rm、覆蓋既有檔案、git reset --hard 等破壞性操作才攔截詢問。
  • 🚀 最高權限（烈焰橘紅）：當前對話全速自動放行。
🖼️

2. 並排共用預覽框 ＋ 右側 Files 自動跟隨

看圖不再蓋住對話框、也不會越開越多分頁：

  • 預設並排、原地換圖：在終端機按 ⌘ Cmd + 點擊檔案路徑（含 file://），會在右半邊並排開啟預覽；再點下一張圖時直接原地換圖。
  • 目錄自動同步＋高亮：預覽圖片時，右側 Files 自動切換至該圖片所在資料夾並高亮檔案，附帶 ↑ 回上一層與 ⌂ 回根目錄按鈕。
  • 四方向鍵切圖＋兩指縮放＋PPT 簡報預覽：支援鍵盤 ← → ↑ ↓ 切圖、觸控板兩指捏合（Pinch）無段縮放，並內建 .pptx / .ppt 16:9 投影片卡片與大綱預覽器（含內嵌圖片提取與講者備忘稿）。
🔵

3. 左側 Agent 列右鍵「標記為未讀藍點」

多個 Agent 同時跑完任務時，點過去看一眼藍點就消失了？現在可以隨時把重要的對話標回來：

  • 在左側 Agents 清單對任何一個 Agent 按滑鼠右鍵彈出下拉選單。
  • 點選 「標記為未讀（顯示藍點）」，即可將空心灰圓環恢復為實心亮藍點與亮白標題（在 Priority 排序下也會自動歸回 Done 區）。
  • 下次左鍵點擊進入該對話時，自動清除未讀藍點恢復已讀。
🎨

4. 三套 AI 統一彩色狀態列 ＋ 70% 轉紅警示

無論你開的是 Claude Code、Antigravity (agy) 還是 Codex，底部狀態列都共用同一套五色塊標準：

  • 順序固定為：[模型名稱] [目前路徑] [Context 已用 %] [權限模式] [對話標題]。
  • Context 警戒變色：平時為沉穩灰底，一旦 Context 用量達 70% 立即自動轉為珊瑚紅底，提醒你適時執行 /compact。
  • 自動將 agy 對話主題同步至 Herdr 側欄與分頁標題。
📋

5. Codex 待複製內容自動標色 ＋ 高對比深色主題

解決 Codex 預設淺色主題在深色終端機下反光看不清、以及「待複製文字」跟一般說明混在一起的問題：

  • 內建 cli-beginner-dark.tmTheme，將多行複製區塊渲染為深藍底色＋亮青色字體。
  • 透過全域 ~/.codex/AGENTS.md 規範所有 📋 ： 後方的待複製指令一律以反引號包住，直接變成醒目的亮青色膠囊文字。
📊

6. 左下三合一用量監控 ＋ Claude Credit 剩餘額度

左下角 over9k-usage 面板一次掌握三大 AI 平台額度：

  • Claude Pro ＋ Credit Est.：除了 5h / 7d 進度條，更支援從基準餘額（claude-credit.json）自動扣除本機新增對話花費，即時顯示預估剩餘美金與 1d / 1w / 30d 每日長條圖。
  • Codex Plus ＆ Gemini Pro：自動讀取本機 session 與狀態列快取，含 5h / 7d 及 3rd-party 模型配額。
